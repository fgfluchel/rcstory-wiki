**CIOD**, the Covert Interspatial Operations Division, is an ultra-classified Tier-1 operational division under [Space Command](space-command.md). It is this universe's equivalent of a special-operations command for interspatial work, and it houses the [17th IEG](17th-ieg.md).

CIOD runs a secure interspatial processing hub, **CIOD Intake Node-7**, used for staging and pre-deployment isolation. CIOD Headquarters is named as a location but hasn't been described yet.
